# 섭외(DM) 리스트 + 소싱 규제 가이드

크롤링 결과를 실제 사업 플로우 — **소싱 → 현지 협업 → 구매대행 결제** — 로 연결하는 단계입니다.

```
JapanHaulCrawler  →  japan_haul_videos_*.csv
                              ↓
                     OutreachBuilder
                              ↓
        outreach_list_*.csv  (섭외 우선순위 + DM 초안 + 발송 대장)
```

---

## 1. 먼저 알아야 할 두 가지 제약

### ① 대량 자동 DM은 만들지 않았습니다

인스타그램은 자동 DM 발송을 약관으로 금지하고, 실제로 몇 시간 안에 계정을 제한합니다.
그리고 무차별 DM은 답장률이 바닥이라 사업적으로도 손해입니다.

그래서 이 도구는 **초안만 생성**하고 발송은 하지 않습니다.
CSV를 열어 우선순위 순으로 직접 보내세요.

| 계정 상태 | 하루 권장 발송량 |
|---|---|
| 신규 / 팔로워 적음 | 10~20건 |
| 워밍업된 계정 (3개월+) | 30~50건 |

한 줄이라도 직접 고쳐서 보내는 쪽이 답장률이 훨씬 높습니다.
초안은 뼈대로만 쓰세요.

### ② 소싱 리스트에서 상당수가 **판매 불가** 품목입니다

크롤링하면 상위권은 대부분 의약품(카베진·샤론파스·이브퀵·오타이산 등)이 차지합니다.
그런데 **의약품은 한국에서 온라인 판매·알선·광고 자체가 약사법 위반**입니다.
개인이 자가사용 목적으로 직구하는 것(최대 6병)과 **판매하는 것은 완전히 다릅니다.**

그래서 아이템 사전에 `regulation` 등급을 넣었습니다.

| 등급 | 의미 | 해당 카테고리 |
|---|---|---|
| `blocked` | 판매 불가 / 사실상 불가 | 의약품 전반, 주류(통신판매 제한), 냉동식품 |
| `restricted` | 가능하나 요건 있음 | 화장품(화장품책임판매업 등록), 식품·건기식(식약처 수입신고), 목록통관 배제 → 간이/일반통관 |
| `ok` | 일반 공산품 | 잡화, 생활용품 (KC 대상 여부만 확인) |

**초기 진입은 `ok` 등급(잡화·생활용품)부터 잡는 걸 권장합니다.**
화장품은 매출이 크지만 화장품책임판매업 등록이 선행되어야 합니다.

> 이 등급은 1차 스크리닝용 참고치입니다. 품목 확정 전 관세사·식약처 확인은 필수입니다.

### 그 외 사업자 요건

- **구매대행업 등록제** — 관세청 등록 대상입니다.
- **통신판매업 신고** — 직전연도 거래 50회 이상이면 의무입니다.
- **개인통관고유부호** — 2026년 2월 2일부터 통관 시 영문 성명·배송주소 유효성 검증이 적용됩니다. 주문 폼에서 이 값을 정확히 받도록 설계하세요.

## 2. 실행

```bash
python OutreachBuilder.py \
  --videos results/japan_haul/japan_haul_videos_20260817_1530.csv \
  --brand "재팬픽" \
  --site "https://japanpick.co.kr" \
  --track all --top 100
```

| 옵션 | 설명 |
|---|---|
| `--track all` | 전체 |
| `--track jp` | **일본 현지 계정만** — 소싱/협업 트랙 (일본어 DM) |
| `--track kr` | 한국 계정만 — 제휴/커미션 트랙 (한국어 DM) |
| `--top N` | 상위 N개만 |

트랙은 캡션의 **가나(히라가나/가타카나) 대 한글 비중**으로 자동 판정합니다.
한자는 한국어 캡션에도 섞이므로 판정에서 제외했습니다.

## 3. 섭외 점수

순위(percentile) 기반이라 단위가 다른 지표를 섞어도 왜곡이 없습니다.

| 가중치 | 지표 | 왜 |
|---|---|---|
| 35% | 평균 조회수 | 도달력 |
| 30% | 참여율 (좋아요+댓글)/조회수 | 팔로워 수를 못 받으므로 대용치. 어그로 계정 걸러냄 |
| 20% | 관련도 (아이템 언급 게시물 / 전체) | 우연히 걸린 계정 배제 |
| 15% | **판매가능 아이템 수** | 규제로 못 파는 아이템만 다루는 계정은 섭외해도 매출이 안 남 |

이 설계 때문에 **조회수 1등이 섭외 1등이 아닙니다.** 테스트에서:

```
     username      트랙   티어  평균_조회수  참여율_%  판매가능_아이템수  섭외점수
 osaka_beauty  제휴/커미션   미들  107,500   7.49          8  83.8
tokyo_kurashi 현지소싱/협업 마이크로   40,000   8.12          3  78.8
 traveler_kim  제휴/커미션   메가  375,000   2.87          1  70.0   ← 조회수 1위인데 3등
```

`traveler_kim`은 조회수가 3.5배 높지만 콘텐츠가 전부 의약품(판매 불가)이고
참여율이 낮아 3위로 밀립니다. **사업적으로 맞는 순서입니다.**

티어는 평균 조회수 기준: 나노 <5천 / 마이크로 5천~5만 / 미들 5만~30만 / 메가 30만+

## 4. 산출물: `outreach_list_<track>_<날짜>.csv`

| 컬럼 그룹 | 컬럼 |
|---|---|
| 식별 | username, 프로필, 추정언어, 트랙 |
| 규모 | 티어, 평균_조회수, 총_조회수, 평균_좋아요, 평균_댓글, 참여율_% |
| 관련도 | 수집_게시물수, 아이템_언급_게시물수, 다루는_아이템 |
| 소싱 | 판매가능_아이템, 판매가능_아이템수 |
| 근거 | 대표_영상, 대표_영상_조회수 |
| 판정 | **섭외점수** |
| 실행 | **DM_초안**, 발송일, 상태, 메모 |

뒤 3개 컬럼은 비어서 나옵니다. **그대로 발송 대장으로 쓰세요.**
`상태`는 `미발송`으로 채워져 있으니 `발송/답장/거절/계약`으로 바꿔가며 관리하면 됩니다.

## 5. 두 트랙의 역할

| | 현지소싱/협업 (`jp`) | 제휴/커미션 (`kr`) |
|---|---|---|
| 대상 | 일본 거주 계정 | 한국 여행/뷰티 계정 |
| 제안 | 현지 매입 대행, 재고 확인, 신상 소싱 | 제휴 링크 커미션, 제품 제공 후 콘텐츠 |
| 목적 | **공급망** 확보 | **수요/트래픽** 확보 |

두 트랙을 동시에 돌려야 파이프라인이 닫힙니다.
현지 파트너만 잡으면 팔 곳이 없고, 한국 인플루언서만 잡으면 물건이 없습니다.

---

## 6. 권장 순서

1. 크롤링을 `--limit 20`으로 한 번 돌려 쿼리 성과 확인
2. `japan_haul_items_*.csv`에서 **규제등급 `ok` / `restricted`** 아이템만 추려 소싱 후보 확정
3. 관세사와 후보 품목 검토 → 사업자등록 / 통신판매업 신고 / 구매대행업 등록
4. `--track jp`로 현지 파트너 20~30곳 컨택 → 매입 단가 확보
5. 단가가 나온 품목만 사이트에 올림
6. `--track kr`로 한국 인플루언서 제휴 시작
